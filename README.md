# Munero Homebrew tap

Homebrew casks for Munero Limited's macOS apps.

```sh
brew install --cask munero/tap/kettle
```

| Cask | App |
|---|---|
| `kettle` | [Kettle](https://github.com/MuneroLtd/kettle-releases) — a menu bar traffic light for every Claude Code session |

Casks here are updated automatically when a release is published; please don't edit them by hand —
changes are overwritten on the next release.
